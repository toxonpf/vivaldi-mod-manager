# Мои CSS-моды для Vivaldi

Выберите эту папку в Vivaldi: **Настройки → Внешний вид → Пользовательские изменения интерфейса**.

Файлы с окончанием `.off` выключены. Чтобы включить мод, переименуйте его в `.css`, например:

```bash
mv compact-tabs.css.off compact-tabs.css
```

Чтобы выключить — верните окончание `.off`. После любого изменения перезапустите Vivaldi.

Здесь можно безопасно хранить и скачанные CSS-моды. Перед добавлением нового файла откройте его в редакторе и посмотрите, что он меняет.
