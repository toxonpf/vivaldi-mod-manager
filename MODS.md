# Каталог модов

| Тип | Имя | Состояние | Назначение |
| --- | --- | --- | --- |
| CSS | `compact-tabs` | выключен | Уменьшает высоту и минимальную ширину вкладок сверху. |
| CSS | `tab-hover-highlight` | выключен | Подсвечивает вкладку под курсором. |
| CSS | `clear-active-tab` | выключен | Добавляет заметную полоску активной вкладке. |
| JS | `tab-colors` | установлен | Открывает палитру по `Shift + ПКМ` на вкладке. |

Статус CSS меняется командой `manage.sh` либо переименованием `.css.off` в `.css`. Статус JS-мода смотрите через `./manage.sh js-status`.

На Windows используйте веб-панель: оболочка `manage.sh` предназначена для Linux.
